# Piet Mondrian Chat

A React and Express application for a Piet Mondrian-themed chat experience.

## Prerequisites

- Node.js 20 or newer
- npm

## Install dependencies

Run these commands from the project root:

```powershell
cd client
npm install
cd ../server
npm install
cd ..
```

## Run the client

In a separate terminal:

```powershell
cd client
npm run dev
```

Open `http://localhost:5173`.

## Run the server

In another terminal:

```powershell
cd server
npm run dev
```
